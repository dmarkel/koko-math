# Koko Math Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish a cute, static Koko Math website that generates 50 first-grade addition and subtraction problems within 20 and prints them on one US Letter page.

**Architecture:** A framework-free HTML/CSS/JavaScript application uses a pure generator module for worksheet data and a small DOM controller for navigation and rendering. A custom generated anime character anchors the landing page while print CSS strips the experience down to a single classroom worksheet.

**Tech Stack:** Semantic HTML5, CSS3, ES modules, Node.js built-in test runner, GitHub Pages

## Global Constraints

- Every operand and answer is a whole number from 0 through 20.
- Every sheet has exactly 50 problems: 25 addition and 25 subtraction.
- Subtraction never produces a negative answer.
- The printable output contains no answer key and fits one portrait US Letter page.
- The source family photo is a generation reference only and must not be published.
- The deployed site has no runtime dependencies, account, server, or network request.
