# Koko Math

Koko Math is a cheerful collection of printable practice sheets for early learners. It includes vertical arithmetic practice and illustrated Grade 1 and Grade 2 word problems.

## Worksheet rules

- Within 20: 50 problems, split evenly between addition and subtraction
- Within 100: 20 problems, split evenly between addition and subtraction
- Within 1,000: 20 problems, split evenly between addition and subtraction
- Every operand and answer is positive; zero never appears
- Subtraction never produces a zero or negative answer
- Problems are stacked vertically with room for carrying and borrowing
- No answer key
- Fits one portrait US Letter page

## Word-problem worksheets

- Grade 1: 10 one-step addition and subtraction stories within 20
- Grade 2: 10 stories within 100, with eight two-step and two one-step problems
- Each worksheet prints on exactly two US Letter pages, five problems per page
- Every problem has a matched black-and-white line-art visual, work space, and an answer line
- **New worksheet** refreshes the complete set with new stories, numbers, ordering, and visuals
- Problems only; no answer key

## Preview locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`, choose the worksheet, and use **Print worksheet**.

## Test

```bash
npm test
```

The site is framework-free and deploys directly from the repository root with GitHub Pages.
